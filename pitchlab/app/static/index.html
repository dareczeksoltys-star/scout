☁️ Integracja z Google Cloud Platform & Cloud Firestore

Jak działa architektura PITCHLAB w GCP:

  • Cloud Firestore: Zarządza kolekcjami matches, shots, events i tags w czasie rzeczywistym.
  • Google Cloud Storage (GCS): Bezpośredni upload wideo przez Signed URLs do gs://pitchlab-data/raw/.
  • Silnik GPU (Cloud Batch / GCE Spot): Zadanie analizy wykonuje się w kontenerze tylko na minuty trwania skrótu (brak kosztu stałego 24/7).
Konfiguracja zmiennych środowiskowych GCP:
export GCP_PROJECT_ID="twoj-projekt-gcp"
export GCS_BUCKET="pitchlab-data"
export GOOGLE_APPLICATION_CREDENTIALS="sciezka/do/service_account.json"
